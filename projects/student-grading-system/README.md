# Student Grading System

A simple C++ program that accepts a student's marks and assigns a performance grade.

## Grading System

| Marks | Result |
|---|---|
| 70 and above | Excellent |
| 60–69 | Good |
| 50–59 | Average |
| 40–49 | Pass |
| Below 40 | Fail |

## Technology

- C++

## How It Works

The program asks the user to enter their marks. It then uses `if`, `else if`, and `else` statements to determine and display the appropriate result.
